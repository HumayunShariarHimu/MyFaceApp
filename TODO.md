# Project outcomes

- [x] **2D portrait intake ও on-device privacy:** user JPG/PNG/WEBP portrait (সর্বোচ্চ 12 MB) upload/drop করে preview/remove করতে পারবেন। Face photo, descriptor ও camera frame application backend-এ persist হয় না; camera explicit click-এর পরে খোলে এবং capture শেষে stream বন্ধ হয়।
- [x] **Photo-led rotatable, animated estimated 3D head avatar:** uploaded 2D portrait-এর face landmarks ও photo texture দিয়ে frontal facial surface তৈরি হবে; surface একটি rotatable procedural head volume-এর সামনে থাকবে, সঙ্গে estimated hair cap, ears ও neck থাকবে। Auto-rotate, drag/preset/zoom, wireframe এবং subtle gaze/blink mesh motion থাকবে। UI side/back/head completion-কে inferred estimate বলবে।
- [ ] **Photo-accurate full 3D identity/photoreal animation:** 2D photo থেকে exact unseen profile/back, true depth বা subject-specific complete anatomy recover করা যাবে না। বর্তমান shell procedural estimate, learned identity-fitted 3D head নয়; natural expression capture, jaw/mouth/cheek rigging এবং photoreal multi-view generation এখনো implement/validate হয়নি। পূরণ করতে licensed pretrained model/weights ও multi-view/depth input, অথবা অনুমোদিত GPU reconstruction service এবং extensive target-device validation লাগবে।
- [x] **Same-device reference/live-face similarity demo:** uploaded original portrait reference এবং fresh browser-camera frame local descriptor দিয়ে 1:1 compare হয়; explicit camera action ও stop behavior আছে। এটা production identity verification নয়: 0.52 threshold calibrated নয়; generated avatar matcher/liveness reference হিসেবে ব্যবহৃত হয় না।
- [ ] **Production-grade verification/PAD:** representative consented dataset-এ threshold/FMR/FNMR evaluation, independent PAD/APCER/BPCER test, camera-injection defense, model provenance/security audit ও jurisdiction-specific privacy controls এখনো নেই। App certified authentication/liveness দাবি করবে না।
- [x] **Research-informed model/license boundary:** `research/face-tech-review.md`-এ open-source model/repo/weights/license, reconstruction, animation, browser/server compute, data and evaluation review করা আছে; code license pretrained model/data permission-এর বিকল্প নয়; user upload থেকে training default-এ বন্ধ।
- [x] **Build and GitHub Pages:** Vite production build সফল হয়েছে; main push-এ GitHub Actions Pages workflow deploy করে।

## নির্ভুলতা ও নিরাপত্তা নোট

বর্তমান app একটি photo-textured facial surface-কে locally generated estimated head shell-এ fit করে; পাশ/পেছনের অঞ্চল generic/generated estimate। Face score uncalibrated demonstration মাত্র। এটি 3D scan, exact likeness, identity proof বা liveness/PAD নয়।
